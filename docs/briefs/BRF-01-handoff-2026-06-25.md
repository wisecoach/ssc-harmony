## 关键架构信息

### 锁系统

| 锁 | 位置 | 范围 | 获取 | 释放 |
|----|------|------|------|------|
| TempLockView | `ssc/temp_lock_view.go` | 链下，仅 leader | `TryLockWithPriority` | `OnBlockCommitted` / `GarbageCollect` / Wound |
| stateLockManager | `ssc/state_lock_impl.go` | 链上，所有节点 | `stateLocker.Lockable` 执行时 | `handleLockCommit.clear()` / `pendingUnlocks.applyTo` |
| PatchPool | `ssc/retry_scheduler.go` | 链下，仅 leader | SimTx 提交时 `Add` | `closeTransaction` / `Release` |

### Wound-Wait 优先级

`TryLockWithPriority` → `canWound` → compare `Priority{FirstSimBlock, Nonce, OriginShardID}`

FirstSimBlock 越小越优先。**永远不会变。**

### 关键流程

```
首次模拟: StartSimulateCXTransaction → LockConflict → CallForRetry
  → AddToRetry → retryPool
  → HandleRetrySignal（所有 related shard 发 Ready 信号后）
  → tryToReSimulation → 向所有 related shard 并发 RetryCommit
    → 全部 locked:true → TriggerReSimulation → StartReSimulation
      → 再次 VM 执行（这次 SetState 会查 Patch，不撞锁）
      → resimulation accomplished ✅ → CommitSimulation → VerifySimulation → CR → closeTransaction
```
